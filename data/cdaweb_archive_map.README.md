# CDAWeb public-archive folder map (`cdaweb_archive_map.json`)

This asset is a **map of the upstream CDAWeb public archive directory tree**,
generated by crawling the live archive listing. It is the upstream mirror of
what the *vendored* observatory catalog
(`src/spedas_agent_kit/backends/cdaweb/data/observatories/`) describes in
curated form; the vendored catalog is a separate asset and is **not** touched
by the crawler.

| Field | Value |
| --- | --- |
| Root | `https://cdaweb.gsfc.nasa.gov/pub/data/` |
| Crawler | `scripts/crawl_cdaweb_archive.py` |
| Listing source | HTTP directory listing (Apache autoindex); FTP (`ftp://cdaweb.gsfc.nasa.gov/pub/data/`) fallback via `ftplib` |
| Generated | `generated_at` field inside the JSON |
| Total nodes | `total_nodes` field |
| Leaf folders | `leaf_folder_count` field |

## What is in the file

Top-level JSON object:

```jsonc
{
  "generated_at": "ISO-8601 UTC",
  "root": "https://cdaweb.gsfc.nasa.gov/pub/data/",
  "total_nodes": 51273,
  "leaf_folder_count": 383,
  "partial": true,              // see "Current snapshot" below
  "limits": {
    "max_depth": 6,             // crawl stopped below this directory depth
    "dir_listings_fetched": 1832,
    "dir_listings_failed": 0,
    "dir_listings_skipped": 0,
    "dirs_pending": 7061,       // dirs seen but not yet listed
    "limit": null               // --limit used for this run, if any
  },
  "elapsed_seconds": 0.0,
  "nodes": [
    {
      "path": "ace/ace_epam/2021",   // relative to the archive root
      "kind": "dir",                 // "dir" | "file"
      "url": "https://cdaweb.gsfc.nasa.gov/pub/data/ace/ace_epam/2021/",
      "children": 365,               // entries in this dir (0 for files)
      "status": 200,                 // HTTP status of the listing request
      "size": null                   // bytes for files, null for dirs
    }
  ]
}
```

A **leaf folder** is a directory that contains data files and no
subdirectories (the final dataset folders where the actual data files live).
`leaf_folder_count` counts those; the full list of leaf folder paths can be
derived from `nodes` (dirs with `status == 200`, `children > 0`, and no
`kind == "dir"` child).

## Current snapshot

> **partial snapshot — run full crawl with `--full`**

The committed snapshot is a **real** crawl but deliberately partial: the full
CDAWeb tree has tens of thousands of folders and the public server throttles
deep crawling, so the committed run was budget-limited (`--limit 2000` on
listing counts; the run in the daemon budget finished with 1832 listings).
It still covers the full first level (all missions), most of the second
level, and part of the third, and contains **51273 nodes / 383 leaf
folders**. `"partial": true` in the JSON means exactly this.

## How to refresh

Requires Python 3.10+ with `requests`:

```bash
# Full crawl of the whole public tree (unlimited, depth 6)
/home/huangzesen/anaconda3/bin/python scripts/crawl_cdaweb_archive.py --full \
    --output data/cdaweb_archive_map.json

# Smoke run: budget the crawl to N directory listings (e.g. 2000)
/home/huangzesen/anaconda3/bin/python scripts/crawl_cdaweb_archive.py \
    --limit 2000 --max-depth 6 \
    --output data/cdaweb_archive_map.json

# Resume a previous run (re-lists only directories that never succeeded)
/home/huangzesen/anaconda3/bin/python scripts/crawl_cdaweb_archive.py \
    --resume --limit 2000 --output data/cdaweb_archive_map.json

# Finalize without any network: rebuild the map from the JSONL sidecar
/home/huangzesen/anaconda3/bin/python scripts/crawl_cdaweb_archive.py \
    --finalize --jsonl data/cdaweb_archive_map.jsonl \
    --output data/cdaweb_archive_map.json
```

The crawler writes results **incrementally** to a JSONL sidecar
(`<output>.jsonl`, one node record per line), so an interrupted run loses at
most the in-flight listing and can be continued with `--resume`. The JSONL
sidecar is a build artifact and is not committed.

## Politeness / safety

* small worker pool (`--workers`, default 6);
* per-request timeout (`--timeout`, default 15 s), one retry per URL;
* crawl budget (`--limit`, `--max-depth`) so the walk can never run unbounded;
* reads only directory listings (child file names/sizes come from the same
  listing, no per-file requests);
* the crawler never writes outside the output paths and never touches the
  vendored observatory catalog, code, or tests.

## Example usage

```bash
# list leaf folder paths
python - <<'EOF'
import json
d = json.load(open('data/cdaweb_archive_map.json'))
nodes = {n['path']: n for n in d['nodes']}
leaves = []
for p, n in nodes.items():
    if n['kind'] != 'dir' or n.get('status') != 200 or n['children'] == 0:
        continue
    prefix = p + '/' if p else ''
    if not any(q.startswith(prefix) and '/' not in q[len(prefix):]
               and m['kind'] == 'dir' for q, m in nodes.items()):
        leaves.append(p)
print(len(leaves))
EOF
```
